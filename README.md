# Libra SMP — Official Server Website

> **"Find your balance. Shape your destiny."**  
> *Your world. Your choices. Your legacy.*

A custom, production-ready, immersive website for **Libra SMP** — a Minecraft survival multiplayer server featuring the **Alter SMP X Origins** system and an equitable community governance philosophy.

---

## ⚖️ Brand & Creative Direction

Libra SMP's visual identity is crafted at the intersection of three design philosophies:
1. **An Immersive Minecraft World:** Cinematic environment layering, atmospheric cherry blossom grove backdrops, beacon light columns, and dusk lighting directly from in-game server screenshots.
2. **Authentic Game Interface:** Minecraft-inspired button bevels, inset inventory slots, dynamic health capacity representations, and pixel typography.
3. **Modern Web Craftsmanship:** Elegant serif headers (Cinzel), high-contrast readable body typography (Inter), responsive multi-column editorial panels, and smooth micro-interactions.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation & Development
```bash
# Install dependencies
npm install

# Start the Vite development server (runs on port 3000)
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
# Typecheck and build optimized static assets to /dist
npm run build

# Preview the production build locally
npm run preview
```

## 🌟 Architecture & Features

### 1. Cinematic Hero
- Layered Minecraft scenery using authentic screenshots (`screenshot-beacon-rain.png`).
- Animated beacon light column simulation.
- Ambient cherry petal drifting particles.
- Prominent server IP (`librasmp.ultramc.co`) with one-click copy button, fallback support, and visual feedback toast.
- Direct Discord community gateway (`https://dsc.gg/libraer`).
- Live server status ticker backed by real data from `api.mcsrvstat.us`.

### 2. Discover Libra SMP
- Interactive editorial tabbed showcase covering:
  - Survival Sandbox & World Generation
  - Alter SMP X Custom Origins
  - Regulated, Fair PvP & Skirmishes
  - Community Alliances & Clan Synergy
- Integrated real player community screenshots (`screenshot-community.png`, `screenshot-cherry-path.png`).

### 3. Origins Codex (Signature Feature)
- Complete bestiary of all **10 Origins**:
  1. **Human** (Standard balanced survival)
  2. **Arachnid** (Web crafting, wall climbing, 7 hearts, carnivore)
  3. **Avian** (Slow fall, high speed, high-altitude sleep, herbivore)
  4. **Blazeborn** (Fire immunity, nether spawn, water vulnerability)
  5. **Elytrian** (Innate gliding, dive damage, chainmail armor limit)
  6. **Enderian** (30s Ender pearl teleport, water vulnerability)
  7. **Feline** (Zero fall damage, 9 hearts, creeper ward, stone limitation)
  8. **Merling** (Aquatic breathing, ocean vision, water bucket dependence)
  9. **Phantom** (Intangible block phasing, 7 hearts, daylight burning)
  10. **Shulk** (9 death-retained inventory slots, built-in natural armor)
- Category filtering (Aerial, Elemental, Agility, Stealth, Utility, Standard) and full-text keyword search.
- Interactive health capacity visualizer displaying actual Minecraft heart containers (7, 9, or 10 hearts).
- Keyboard navigation (Arrow keys `←` and `→` to cycle origins).

### 4. Fairness and Transparency
- Architectural diagram explaining the **10–12 member Board of Directors** operating on equal permissions and shared governance.
- Transparent logging model: daily server logs and UltraServers activity panel audits.
- Dual jurisdiction protecting players across both Minecraft and Discord.

### 5. Staff & Leadership Directory
- Roster layout for 9 organizational roles:
  - Server Owners
  - Board of Directors (10–12 members)
  - Community Manager
  - Developer
  - Senior Staff
  - Moderator
  - Trial Moderator
  - Trial Staff
  - Staff Team
- Role duties, charters, and privacy-first application directions.

### 6. Rules & Regulations Codex
- Searchable & tabbed codex across 3 categories:
  - **Minecraft Rules:** 9 enforceable gameplay rules (No cheats/X-Ray, fair combat, anti-dupe, no alt abuse, etc.).
  - **Discord Rules:** 15 community guidelines with direct links to official Discord Terms of Service and Community Guidelines.
  - **Disciplinary Actions:** Transparent graduated sanctions (Warnings, confiscation, timeouts, temporary bans, permanent bans).

### 7. Join Section & Multiplayer Guide
- Step-by-step Java Edition walkthrough (Java 1.20+ supported via ViaVersion).
- Bedrock Edition status disclosure: clearly communicates ongoing Ultimate Hosting Singapore port testing without fabricating unverified ports.

### 8. Announcements Board
- Reusable announcement template featuring the active **Origin Re-Roll Referral Event** (Deadline: 8 November 2026).
- Strict anti-fraud audit terms.

### 9. Community & Support Dispatch
- 7 categorized support avenues routing players directly into private, audited Discord support ticket channels.

### 10. Hidden Easter Egg
- Press the `B` key (or click the secret emblem) to unlock the **Secret Scales of Equilibrium** modal.
